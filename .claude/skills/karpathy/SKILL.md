# Karpathy Guidelines

> Kaynak: https://github.com/multica-ai/andrej-karpathy-skills

## 4 Prensip

### 1. Think Before Coding
- Varsayımları açıkça belirt
- Emin değilsen sor
- Belirsizlik varsa sun

### 2. Simplicity First  
- Minimum kod
- Spekülatif özellik yok
- 200 satır 50 olabiliyorsa yeniden yaz

### 3. Surgical Changes
- Sadece gerekli değişiklik
- Yan kod "iyileştirme" yok
- Her satır isteğe trace edilmeli

### 4. Goal-Driven
- Test yaz → doğrula
- Bug düzelt → önce test yaz
- Başarı kriteri tanımla
